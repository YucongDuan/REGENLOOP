# REGENLOOP

**Personal Regenerative Ecosystem and AI Co-evolution System**

> AI should not live your life for you. It should help human capability, relationships, contribution, and future options grow again.

Version 1.0.0; snapshot 2026-08-19; Apache-2.0.

Open `site/index.html` or run `python dist/RegenLoop.pyz selftest`.

REGENLOOP uses ecological restoration as a systems-design metaphor. It is not clinical, psychological, legal, employment, or financial advice, and it produces no total life score.
